# PocketCart

## English

PocketCart is a mobile e-commerce / marketplace application developed as a university team project.

The goal of the project was to build a complete mobile marketplace where users can publish product listings, search and purchase items, communicate in real time, and manage their personal activity within the platform.

### Main Features

- User registration and login
- Product listing creation
- Advanced product search with dynamic queries
- Saved searches with automatic notifications when matching products become available
- In-app purchase flow with account balance management
- User location management through Google Maps APIs
- Distance calculation between users and listed products
- Real-time messaging between users
- Favorites management
- Overview of listed and purchased products
- Review system
- Firebase / Firestore-based backend

### Project Status

This project was developed several years ago as a university team project.  
The application is currently still available for download, but some features may not work correctly due to deprecated dependencies, external API changes, or backend configuration issues.


## Italiano

PocketCart è un’applicazione mobile di e-commerce / marketplace sviluppata come progetto universitario in team.

L’obiettivo del progetto era realizzare un marketplace mobile completo, in cui gli utenti potessero pubblicare annunci di vendita, cercare e acquistare prodotti, comunicare in tempo reale e gestire la propria attività all’interno della piattaforma.

### Funzionalità principali

- Registrazione e login degli utenti
- Creazione di annunci di vendita
- Ricerca avanzata dei prodotti tramite query dinamiche
- Salvataggio delle ricerche con notifiche automatiche quando diventano disponibili nuovi prodotti compatibili
- Flusso di acquisto tramite gestione del conto interno
- Gestione della posizione dell’utente tramite Google Maps APIs
- Calcolo della distanza tra utente e prodotti in vendita
- Messaggistica in tempo reale tra utenti
- Gestione dei prodotti preferiti
- Visualizzazione dei prodotti messi in vendita e acquistati
- Sistema di recensioni
- Backend basato su Firebase / Firestore

### Stato del progetto

Il progetto è stato sviluppato alcuni anni fa come progetto universitario in team.  
L’applicazione risulta attualmente ancora disponibile per il download, ma alcune funzionalità potrebbero non funzionare correttamente a causa di dipendenze deprecate, cambiamenti nelle API esterne o configurazioni del backend non più aggiornate.
